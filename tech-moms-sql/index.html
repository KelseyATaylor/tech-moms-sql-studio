Your SQL cheat sheet

SQLite powers this sandbox. Table and column names with spaces need double quotes.

Choose columns
SELECT name, city FROM customers;
Filter rows
SELECT * FROM orders WHERE total > 50;
Sort results
SELECT * FROM orders ORDER BY total DESC;
Count by group
SELECT city, COUNT(*) FROM customers GROUP BY city;
Combine tables
SELECT c.name, o.total FROM customers c JOIN orders o ON c.id = o.customer_id;

Run highlighted text or the entire editor with Ctrl+Enter (⌘+Enter on Mac). Changes affect only this tab’s database. Save a database file before closing to keep them.

Squiggles check whether SQLite can prepare your query. Some issues only appear when you run it. Queries stop after 8 seconds; stopping restores the last completed run.
